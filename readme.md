# Smart Leads Dashboard

Smart Leads Dashboard is a MERN stack lead management application built using React, TypeScript, Node.js, Express, and MongoDB. It allows users to authenticate, manage leads, search/filter data, and monitor lead status from a clean dashboard UI.

---

## Features

- User Registration and Login
- JWT Authentication
- Protected Routes
- Add New Leads
- View Leads Dashboard
- Search Leads
- Filter Leads by Status
- Lead Statistics Cards
- Logout Functionality
- Responsive Dashboard UI
- MongoDB Database Integration

---
